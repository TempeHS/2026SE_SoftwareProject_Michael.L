# Huddle

Huddle is a Progressive Web App (PWA) designed to help friend groups organise social plans through event proposals, voting, and attendance tracking.

## Current Status
Current Sprint: Sprint 1  
Last Increment: Initial project setup and authentication planning completed.  
Next Planned Increment: Build login system and group creation features.

## Features
- User authentication with Google Authenticator 2FA
- Group creation and invite codes
- Event proposal system
- Yes/No/Maybe voting
- Attendance tracking
- Responsive PWA interface

## How to Run
1. Open the project in VS Code
2. Install dependencies
3. Run backend server
4. Open localhost in browser
